# Nationals — каскадное управление VEX V5

Рабочий контур X-drive: **траектория → LTV-LQR → кинематика четырёх колёс → PID скорости + feedforward → напряжение моторов**. Переключений PID/LQR/Hybrid в автономном контуре нет. Внутренний D по умолчанию равен нулю, как в примере 1516X: это PI + kS/kV/kA.

Исходные библиотеки LemLib, PedroFollower, EKF, MCL, FLC, ColorSorter и дифференциальный LTV сохранены. Их наличие не означает, что все они одновременно подключены к роботу. Текущий `main.cpp` использует X-drive, энкодеры четырёх моторов, LTV-каскад и монитор моторов. IMU, внешние tracking wheels, intake и другие механизмы в этой конфигурации не подключены.

## Файлы и запуск

- `config/robot.json` — текущие порты и геометрия. После изменения: `node tools/generate-config.js`.
- `include/autonomous.hpp` — API движений; все функции используют один каскад.
- `include/subsystems/control/Cascade.hpp` — переносимое ядро LTV-LQR и четырёх регуляторов скорости.
- `src/subsystems/control/HolonomicMotion.cpp` — получение датчиков, время, отмена и безопасный вывод на PROS.
- `simulator/` — браузерная модель с тем же C++-ядром и генераторами траекторий, собранными в WebAssembly.
- [Отчёт восстановления](docs/recovery/REPORT.md) — изменения, доказательства и ограничения.

Запуск симулятора из корня проекта:

```powershell
.\tools\start-simulator.ps1
```

Открыть http://127.0.0.1:8765. Нужен HTTP-сервер: прямой запуск HTML через `file://` не загружает WASM. Пакет `control.wasm` включён в проект. Для 3D пока нужен доступ к CDN Three.js.

## Competition flow

При отключённом роботе центральная кнопка LCD выбирает маршрут: каскадная демонстрация, holonomic skills или Bézier. Это выбор маршрута, а не регулятора. Демонстрация выполняет сплайн к `(24,24,90°)` и возвращается в `(0,0,0°)`. Следующий шаг не запускается, если предыдущий не завершился со статусом `Settled`.

В driver control: A — отмена; B — 24″ вперёд; Y — 90°; X — стрейф 24″; LEFT — 180°; DOWN — диагональ; RIGHT — Bézier; R1 — сплайн; UP — отдельные колёса; L1 — сброс позы. Сброс позы выполняйте только в известном физическом положении.

API использует дюймы и градусы CW от +Y. Внутри каскада — метры, м/с, радианы и вольты. `timeout=0` рассчитывает срок по длительности профиля; положительный timeout — миллисекунды. Исторические имена `autoPIDDrive/autoPIDTurn` оставлены как совместимые обёртки и больше не меняют контроллер. Прямой joystick и тест отдельных колёс являются ручным управлением и диагностикой.

## Проверки

```powershell
node tools/generate-config.js --check
node tests/control-core.test.js
node simulator/test_override.js
node simulator/test_holonomic_drive.js
node simulator/test_physics.js
```

Сборка браузерного C++-модуля требует Zig 0.14.1:

```powershell
.\tools\build-wasm.ps1 -Zig C:\path\to\zig.exe
.\tools\test-safety.ps1 -Zig C:\path\to\zig.exe -Cache C:\path\to\cache
```

`control-build.json` связывает WASM с хешами исходников; тест останавливается, если сборка устарела. Полная проверочная ARM-сборка:

```powershell
.\tools\verify-arm-build.ps1 -Repository . -ToolchainBin C:\path\to\pros-toolchain\usr\bin -BuildDirectory .\.cache\arm-check
```

Проверочная сборка не загружает прошивку. Для обычного процесса PROS используйте штатные `pros make`/`pros upload` после проверки конфигурации физического робота.

## Границы достоверности

Симулятор исполняет реальный C++-контроллер, генератор quintic-сплайнов и математику Bézier. Он **не эмулирует PROS, планировщик V5 и всю прошивку**. Моторы, сцепление, батарея и контакт с полем — приближённые модели без идентификации на вашем роботе. EKF на экране — фильтр той же одометрии, а не независимый источник абсолютных координат. Wheel odometry не может обнаружить любое проскальзывание.

Override содержит исправленный инвентарь, расположение по FO-1/FO-2, счёт, автономный снимок, Toggle, владение, match loads и действия с предметами. Это ещё **не полная копия игры**: нет точной CAD-геометрии поля, свободной динамики падающих стопок, реального манипулятора и полного автоматического судейства. Старые AWP/Goal Rush маршруты относятся к прежним игровым предположениям и не являются готовыми автономками Override.
